# homebrew-tap

Homebrew tap for [PortKilla](https://github.com/mukes555/PortKilla) — a native
macOS menu-bar port manager.

## Install

```bash
brew tap mukes555/tap
brew install --cask portkilla
```

The cask always pulls the latest PortKilla release (a universal DMG/zip built by
the app's release workflow), so it stays current without per-release updates.
